# Interactive Notebooks (Binder)

This directory contains interactive Jupyter notebooks designed to be run using **Binder**.

Binder provides a temporary, cloud-based Jupyter environment so you can run and explore the notebooks without installing anything locally.

---

## What to Expect When Using Binder

### ⏳ Startup Time
Binder sessions are created on demand.

- Initial startup may take **1–3 minutes**
- Subsequent launches are often faster due to caching
- Please be patient while the environment is prepared

---

### 🧪 Temporary Sessions
Binder sessions are **ephemeral**.

- Any files or changes you make **will be lost** when the session ends
- If you want to keep work:
  - Download notebooks or files before closing
  - Or copy code/results elsewhere

Binder is best used for exploration, not long-term work.

---

### 📁 Working with Multiple Notebooks
Once the environment is running:

- You can open and run **any notebook in this directory**
- You can explore multiple notebooks in the **same session**
- Outputs, variables, and files persist **within the active session**

You do **not** need to relaunch Binder for each notebook.

---

### 💻 Minimal Environment
Binder provides a clean, minimal Jupyter environment:

- No custom UI extensions
- No saved settings or layouts
- Focused on running code and viewing results

This is intentional and helps ensure consistency across users.

---

## How to Use This Section

1. Wait for Binder to finish starting
2. Open a notebook from the file browser
3. Run cells as instructed in the notebook
4. Explore freely, knowing the session is temporary

A content guide for these notebooks will be added separately.

---

## Notes

- Binder environments are shared public resources
- Long-running computations may time out
- If something fails unexpectedly, refreshing the session often helps

---

Enjoy exploring!
